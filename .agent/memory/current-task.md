## 模板说明

### 触发时机
1. **任务开始前**：读取本文件，根据任务类型快速检索历史经验
2. **任务进行中**：及时记录关键决策和遇到的问题
3. **任务结束后**：填写汇总信息，补充标签，准备归档

### 记录规范
- **关键决策**：记录"为什么这样做"而不是"做了什么"，包含代码示例
- **问题根因**：记录根本原因，不是表面现象
- **修改文件**：记录实际修改的文件路径和行数
- **测试验证**：记录具体测试场景和验证命令
- **数据对比**：尽量提供精确的统计数据
- **归档标签**：任务结束后补充3-5个标签，便于后续检索
- **Memory MCP 同步**：重要信息同时记录到本地记忆和 Memory MCP

---

### ⚠️ 路径规范（重要！）
- **从 `.agents/memory/history/` 出发的相对路径**：
  - 规则文件: `../../rules/xxx.md`
  - 项目源码: `../../../camika-web-official/src/...`
- **验证方法**：使用 `os.path.relpath()` 或手动确认层级关系
- **建议**：写完路径后快速验证是否能正确跳转
